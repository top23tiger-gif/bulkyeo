# 불켜 (bulkyeo)

갤럭시 탭 S9 FE+ (SM-X610) 용 **음성 조명 앱**입니다.
밤에 자다 깼을 때 **"불켜"** 라고 말하면 화면이 하얗게 최대 밝기로 켜지고, **"불꺼"** 라고 말하면 다시 어두워집니다.

> 참고: 갤럭시 탭 S9 FE+ 에는 뒷면 LED 플래시가 없어서, **화면 자체를 조명으로** 씁니다.
> (플래시가 있는 기기에서는 플래시도 같이 켜집니다.)

## 사용법 (v3: 앱을 닫아도 동작, 배터리 절약)

1. 「불켜」 앱을 한 번 열고 권한을 허용합니다.
   - 마이크, 알림 허용
   - **전체 화면 알림 허용** (화면이 꺼져 있을 때 조명을 띄우는 데 필요, 알람 앱과 같은 방식)
2. "✅ 듣고 있어요" 가 보이면 **앱을 닫아도 됩니다.** 알림창에 "불켜: 듣고 있어요" 가 계속 표시됩니다.
3. 명령어
   | 말하기 | 동작 |
   |---|---|
   | "불켜", "불 켜줘", "켜" | 화면이 켜지고 흰색 + 최대 밝기 |
   | "불꺼", "불 꺼줘", "꺼" | 조명 화면 닫힘 (잠시 후 화면 꺼짐) |
4. 조명 화면은 **두 번 톡톡** 눌러도 닫힙니다.
5. 멈추려면 알림의 **[중지]** 를 누르세요. 탭을 **재부팅하면 앱을 한 번 다시 열어야** 합니다 (안드로이드 보안 규칙).

## 배터리 절약 (v3)

- **충전 중에만 듣기** (기본 켜짐): 충전기를 빼면 마이크를 완전히 끄고 쉽니다. 다시 꽂으면 자동으로 다시 듣습니다.
- **정해 둔 시간에만 듣기** (기본: 밤 9시 ~ 아침 6시): 그 밖의 시간에는 쉽니다.
- **배터리 효율 모드** (켜고 끄기): 소리 센서 샘플링 레이트를 16kHz → 8kHz 로 낮춥니다. 인식 정확도가 조금 떨어질 수 있습니다.
- **실제 배터리 측정**: 충전기 없이 30분 넘게 들으면 앱 화면에 "몇 시간에 몇 % 사용" 이 표시됩니다.
- **소리가 날 때만 인식** (항상 적용): 평소에는 소리 크기만 가볍게 확인하고, 목소리 정도의 소리가 날 때만 음성 인식을 잠깐 돌립니다.
  말 시작 부분을 놓치지 않도록 직전 0.8초 소리를 기억해 둡니다.
- 밤새 충전으로 배터리가 상하지 않게 탭의 **설정 → 배터리 → 배터리 보호** 를 켜 두세요.

## 녹음 모음

- 먼저 **앱 안에** 모아 두고, **일주일마다 자동으로 이 기기의 파일**로 옮깁니다. 옮기기에 성공한 녹음은 앱에서 지웁니다.
  - 위치: 내 파일 → Recordings → 불켜 → `2026-11-16` (날짜 폴더) → `2026-11-17_02-10-33.wav` (날짜_시간)
  - 지금 녹음 중인 밤은 다음 주에 옮깁니다.
- 앱 화면 → **녹음 모음 보기** 에서 듣기 / 지금 바로 옮기기 / 지우기.
- 하룻밤 최대 300개까지. 설정에서 끌 수 있습니다.

## 보안 / 개인정보

- **인터넷 권한 없음**: 앱 자체는 인터넷에 연결하지 않습니다.
- **음성 인식**: 소리가 날 때만 두 가지 인식기를 함께 씁니다.
  - 기기 안 인식 (Vosk 한국어 모델): 인터넷 없이 동작.
  - 구글/삼성 음성 인식 (처음 버전에서 잘 되던 것): 더 정확. 소리가 난 몇 초만 넘겨 줍니다. 설정에서 끌 수 있고, 끄면 소리가 기기 밖으로 나가지 않습니다.
- **10분 테스트 모드**: 시간·충전 조건을 무시하고 바로 들어 봅니다. 화면에 "마지막으로 들은 말" 이 표시됩니다 (저장되지 않음).
- **인식한 글자는 저장하지 않음**. 녹음은 위 '녹음 모음' 설정이 켜져 있을 때만, 앱 안에만 저장됩니다.
- 마이크 사용 중에는 **항상 알림 표시** (몰래 듣지 않음).
- 조명 화면은 잠금 화면 위에 뜨지만 **잠금은 풀리지 않습니다.**
- 다른 앱이 이 앱의 화면/서비스를 조종할 수 없게 막아 두었습니다 (exported=false).
- 백업/기기 이전 시 데이터 복사 안 함, 디버그 기능 꺼진 정식(release) 빌드.
- 음성 인식 "띵" 소리가 없어서 소리를 끄지 않습니다.

## 설치 방법 (APK 받기)

1. GitHub 저장소 → **Actions** 탭 → 가장 최근 "Build APK" 실행 클릭
2. 아래 **Artifacts** 에서 `bulkyeo-apk` 다운로드 → 압축 풀면 `app-release.apk`
3. 탭으로 옮겨서 실행 → "출처를 알 수 없는 앱 설치" 허용 → 설치
4. 처음 실행할 때 **마이크 권한 허용**

## 탭 설정 팁

- 설정 → 디스플레이 → **화면 자동 꺼짐** 은 앱이 알아서 막지만, 충전 중이 가장 안정적입니다.
- 설정 → 배터리 → 「불켜」 앱을 **절전 예외(제한 없음)** 로 두세요.
- 음성 인식이 안 되면 설정 → 일반 → **음성 입력 / 음성 인식 서비스**에서 Google 또는 삼성 음성 인식이 켜져 있는지 확인하세요.
  오프라인 한국어 음성 팩을 받아 두면 와이파이 없이도 동작합니다.
- 앱이 켜져 있는 동안 음성 인식 "띵" 소리를 막기 위해 미디어/시스템 소리를 음소거합니다. 앱에서 나가면 원래대로 돌아옵니다.

## 직접 빌드

먼저 `./scripts/download-model.sh` 로 음성 모델을 받은 뒤, Android Studio 로 이 폴더를 열고 ▶ 실행하거나 `gradle assembleRelease`.
