# 불켜 (bulkyeo)

갤럭시 탭 S9 FE+ (SM-X610) 용 **음성 조명 앱**입니다.
밤에 자다 깼을 때 **"불켜"** 라고 말하면 화면이 하얗게 최대 밝기로 켜지고, **"불꺼"** 라고 말하면 다시 어두워집니다.

> 참고: 갤럭시 탭 S9 FE+ 에는 뒷면 LED 플래시가 없어서, **화면 자체를 조명으로** 씁니다.
> (플래시가 있는 기기에서는 플래시도 같이 켜집니다.)

## 사용법 (v2: 앱을 닫아도 동작)

1. 「불켜」 앱을 한 번 열고 권한을 허용합니다.
   - 마이크, 알림 허용
   - **전체 화면 알림 허용** (화면이 꺼져 있을 때 조명을 띄우는 데 필요, 알람 앱과 같은 방식)
2. "✅ 듣고 있어요" 가 보이면 **앱을 닫아도 됩니다.** 알림창에 "불켜: 듣고 있어요" 가 계속 표시됩니다.
3. 명령어
   | 말하기 | 동작 |
   |---|---|
   | "불켜", "불 켜줘", "켜" | 화면이 켜지고 흰색 + 최대 밝기 |
   | "불꺼", "불 꺼줘", "꺼" | 조명 화면 닫힘 (잠시 후 화면 꺼짐) |
4. 조명 화면은 **두 번 톡톡** 눌러도 닫힙니다.
5. 멈추려면 알림의 **[중지]** 를 누르세요. 탭을 **재부팅하면 앱을 한 번 다시 열어야** 합니다 (안드로이드 보안 규칙).

## 보안 / 개인정보

- **인터넷 권한 없음**: 앱 자체는 인터넷에 연결하지 않습니다.
- **가능하면 기기 안에서 음성 인식** (소리가 밖으로 나가지 않음). 기기 안 한국어 인식이 없을 때만 기본 음성 인식 서비스를 씁니다.
- **인식한 말은 저장하지 않음**: "불켜/불꺼" 인지 확인만 하고 버립니다.
- 마이크 사용 중에는 **항상 알림 표시** (몰래 듣지 않음).
- 조명 화면은 잠금 화면 위에 뜨지만 **잠금은 풀리지 않습니다.**
- 다른 앱이 이 앱의 화면/서비스를 조종할 수 없게 막아 두었습니다 (exported=false).
- 백업/기기 이전 시 데이터 복사 안 함, 디버그 기능 꺼진 정식(release) 빌드.
- 밤(화면 꺼짐)이나 조명 화면일 때만 "띵" 소리를 막기 위해 미디어 소리를 잠시 끕니다.

## 설치 방법 (APK 받기)

1. GitHub 저장소 → **Actions** 탭 → 가장 최근 "Build APK" 실행 클릭
2. 아래 **Artifacts** 에서 `bulkyeo-apk` 다운로드 → 압축 풀면 `app-release.apk`
3. 탭으로 옮겨서 실행 → "출처를 알 수 없는 앱 설치" 허용 → 설치
4. 처음 실행할 때 **마이크 권한 허용**

## 탭 설정 팁

- 설정 → 디스플레이 → **화면 자동 꺼짐** 은 앱이 알아서 막지만, 충전 중이 가장 안정적입니다.
- 설정 → 배터리 → 「불켜」 앱을 **절전 예외(제한 없음)** 로 두세요.
- 음성 인식이 안 되면 설정 → 일반 → **음성 입력 / 음성 인식 서비스**에서 Google 또는 삼성 음성 인식이 켜져 있는지 확인하세요.
  오프라인 한국어 음성 팩을 받아 두면 와이파이 없이도 동작합니다.
- 앱이 켜져 있는 동안 음성 인식 "띵" 소리를 막기 위해 미디어/시스템 소리를 음소거합니다. 앱에서 나가면 원래대로 돌아옵니다.
