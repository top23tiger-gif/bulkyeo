# 엄마의 영어 한 문장

정해진 시간마다 영어 문장을 알림으로 보내 주는 안드로이드 앱입니다.
알림을 누르면 상황을 보여주는 그림이 화면 가득 나오고, 그 위에 영화 자막처럼 영어 문장과 한글 뜻이 나옵니다.

- **인터넷과 API를 쓰지 않습니다.** 문장, 그림, 알림, 영어 음성이 모두 폰 안에서 처리됩니다.
- 기본 알림 시간은 **오전 9시, 오후 1시, 오후 8시**이고, 앱에서 추가하거나 바꾸거나 지울 수 있습니다.
- 알림이 올 때마다 다음 문장으로 넘어갑니다. 지금은 30문장(10가지 상황 × 3문장)이 들어 있습니다.
- 🔊 **듣기** / 🐢 **천천히**: 폰에 들어 있는 음성 엔진으로 영어를 읽어 줍니다.
- 🖼 **배경 바꾸기**: 폰 갤러리의 사진(좋아하는 영화 장면 캡처 등)을 그 문장의 배경으로 쓸 수 있습니다.

## 엄마 폰에 설치하기

1. 엄마 폰에서 이 저장소의 [`apk/mom-english.apk`](apk/mom-english.apk) 파일을 내려받습니다.
   카카오톡으로 파일을 보내도 됩니다.
2. 파일을 열면 "출처를 알 수 없는 앱" 경고가 나옵니다. **설정 → 이 출처 허용**을 켜고 설치합니다.
3. 앱을 처음 열 때 **알림 허용**을 눌러 줍니다.
4. **"🔔 지금 알림 한번 받아보기"** 버튼을 눌러서 알림이 잘 오는지 확인합니다.

### 알림이 안 올 때 (특히 삼성 폰)

삼성 폰은 배터리를 아끼려고 잘 안 쓰는 앱을 재울 수 있습니다.
**설정 → 애플리케이션 → 엄마의 영어 한 문장 → 배터리 → "제한 없음"** 으로 바꿔 주세요.

### 영어 음성이 안 나올 때

**설정 → 일반 → 텍스트 음성 변환(TTS)** 에서 영어 음성 데이터를 설치해 주세요.

## 문장과 그림 추가하기

- 문장: [`app/src/main/assets/sentences.json`](app/src/main/assets/sentences.json)에 한 줄씩 추가합니다.
  ```json
  {"en": "영어 문장", "ko": "한글 뜻", "situation": "어떤 상황에서 쓰는지 설명", "image": "cafe"}
  ```
- 그림: `app/src/main/assets/images/`에 있는 `이름.jpg` 파일을 `image`에 적은 이름으로 씁니다.
  세로 사진(9:16)이 가장 잘 어울립니다. 화면 아래쪽 1/3에는 자막이 올라갑니다.
- 지금 들어 있는 그림 10장(cafe, airport, restaurant, street, shop, hotel, kitchen, park, phone, party)은
  `tools/scenes/scenes.js`로 직접 그린 일러스트입니다. 다시 만들려면 `node tools/scenes/render.js`를 실행합니다(Playwright 필요).

> 영화나 애니메이션 장면은 저작권이 있습니다. 엄마 폰에서 혼자 보는 용도로 "배경 바꾸기"에 넣는 건 괜찮지만,
> 그 그림을 앱에 넣어 다른 사람에게 나눠 주지는 마세요.

## 직접 빌드하기

Android SDK(platform 35)와 JDK 17 이상이 있으면 됩니다.

```bash
./gradlew assembleRelease
# 결과: app/build/outputs/apk/release/app-release.apk
```

`keystore/family.jks`는 이 가족용 앱의 서명 키입니다. 같은 키로 서명해야 새 버전을 기존 앱 위에 덮어 설치할 수 있습니다.
덮어 설치하면 알림 시간 같은 설정이 그대로 남습니다. 비밀번호는 `app/build.gradle.kts`에 있습니다.
앱을 스토어에 올린다면 새 키를 만들고 비밀번호를 저장소 밖에 두세요.

## 코드 구조

| 파일 | 역할 |
|---|---|
| `MainActivity.kt` | 첫 화면: 최근 문장 미리보기, 알림 시간 추가·변경·삭제 |
| `SentenceActivity.kt` | 그림 배경 + 자막 화면, 듣기(TTS), 이전·다음, 배경 바꾸기 |
| `Alarms.kt` | 알람 예약(AlarmManager), 알림 표시, 재부팅 후 다시 예약 |
| `Sentences.kt` | 문장·그림 읽기 |
| `Prefs.kt` | 알림 시간, 다음 문장 번호 저장 |
